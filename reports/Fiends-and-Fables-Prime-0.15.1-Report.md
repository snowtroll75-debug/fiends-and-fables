# Fiends & Fables Prime 0.15.1

12 October 2026. Requires TRG Prime 3.636.0. This release fixes one figure found when testing 0.15.0 live.

**The Azur's Smithing is now +10, as printed.** 0.15.0 set it to +12. Core already adds the +2 class bonus to a specialist skill, on top of the base of level, ability and +2, and the extra +4 the module added was counted on top of that. The module's own bonus is now +2: a base of 6, plus 2 for the class, plus 2 = 10.

`verify-module-block6` (19 checks) checks the new figure.
